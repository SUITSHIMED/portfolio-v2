# Portfolio v2

A simple personal portfolio website built with React, Vite, TypeScript, and Tailwind CSS.

## Overview

This project is a portfolio template featuring:
- Hero section
- About section
- Skills display
- Experience timeline
- Project showcase
- Contact form

## Tech Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- lucide-react for icons

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```

Lint the project:

```bash
npm run lint
```

## Project Structure

- `src/` — main source files
- `src/components/` — reusable UI components
- `src/sections/` — page sections
- `src/data/` — navigation, projects, skills, and tech data
- `public/` — static assets

## Notes

This is a private portfolio project configured with modern frontend tooling and type-safe development.
